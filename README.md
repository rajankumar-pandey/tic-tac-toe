# Tic-Tac-Toe Game (Python & Tkinter)

An interactive, clean, and lightweight 2-player **Tic-Tac-Toe** desktop game built using Python and the native **Tkinter** GUI library.

---

##  Features

* **Interactive GUI:** Smooth, simple desktop user interface using Tkinter buttons.
* **Turn-Based Logic:** Automated turn switching between Player 'X' and Player 'O'.
* **Smart Game Rules:** 
  * Automatically checks all 8 possible winning combinations (rows, columns, diagonals).
  * Automatically detects ties when the grid is full without a winner.
* **Auto-Reset:** Automatically resets the board after a match concludes so you can play again instantly.

---

##  Requirements

* **Python 3.12
* **Tkinter** (Typically comes pre-installed with standard Python setups)
